Safety & source notes

Important: This tool does not contain a verified drug-dose database. The uploaded BSAVA file is an index only and does not provide dose instructions. Do not use this app to select or confirm a dose. Verify species, indication, route, interval, maximum dose, contraindications, and patient-specific factors with the full monograph and a supervising veterinarian.

Calculation: dose (mg/kg) × body weight (kg) = total mg per administration. If concentration is entered, total mg ÷ concentration (mg/mL) = mL per administration. This tool does not calculate tablet fractions or daily maximums.
